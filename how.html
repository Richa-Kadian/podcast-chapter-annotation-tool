How it works

Three real steps, then four small algorithms.

Nothing here is a separate tool bolted onto another — one upload flows straight through to a test tied to the recording itself.

01

Upload

Drop in audio or video. Momento reads its real length in the browser and starts building a synced transcript against it.

02

Watch & learn

The transcript highlights itself line by line as it plays, and topic shifts are detected automatically as chapters.

03

Test & review

Get quizzed on what was actually said. Miss one, and it jumps you straight back to the second that answers it.

Algorithm 01

Binary-search timestamp sync

Finds which transcript line is active for the current playback time in O(log n) instead of scanning the whole transcript on every frame.

Algorithm 02

Keyword-frequency chapter detection

Slides a small window across the transcript and marks a new chapter wherever the dominant keyword changes and holds — not on a single stray mention.

Algorithm 03

Rule-based quiz generation

Picks a line per chapter, blanks its keyword, and builds multiple-choice options using other chapters' keywords as distractors — no external LLM required.

Algorithm 04

Streak & scoring engine

Tracks attempts per recording, computes a percentage score, and maintains a day-over-day streak with simple badge thresholds.

Transcripts, chapters, notes, and quiz history are saved to this browser's LocalStorage. The uploaded audio/video file itself is kept in SessionStorage as an object URL, so it's available for playback until the tab closes.

The same four algorithms move server-side in a full rebuild — a real backend stores everything instead of LocalStorage, AI calls are proxied so no key ever reaches the browser, and multilingual captions, timestamp-pinned comments, and spaced-repetition retesting get added.
